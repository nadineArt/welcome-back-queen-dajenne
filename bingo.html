Spiel 04

Toxic Bingo

Beim Erzählen von Ex-Storys die Felder abhaken — wer zuerst BINGO hat, gewinnt!

📋 Spielregeln

  1. Druckt die Bingo-Karten aus — jede Freundin bekommt eine andere Karte.
  2. Dajenne (oder eine andere) erzählt Stories vom Ex.
  3. Wenn eine Verhaltensweise, die auf eurer Karte steht, erwähnt wird → Feld abhaken!
  4. Wer als erste eine Reihe (horizontal, vertikal oder diagonal) voll hat, ruft BINGO!
  5. Das mittlere Feld ist immer ein Freifeld. 🎁
